# SyncMyEnv — landing

Marketing site for [syncmyenv.com](https://syncmyenv.com), built with [Astro](https://astro.build).

```bash
pnpm install
pnpm dev          # http://localhost:4321
pnpm build        # type-check + static build -> dist/
pnpm preview
```

```text
src/pages/        routes (index.astro)
src/layouts/      Base layout (meta, global styles)
src/components/   UI components
public/           static assets
```
